# 🚀 Speaker Persona App - Demo Guide\n\n## Quick Demo Setup\n\n### Prerequisites\n- Node.js (v16 or higher)\n- npm or yarn\n- Modern web browser\n\n### Installation\n\n**Option 1: Automated Setup (Recommended)**\n```bash\n# On Windows\n./setup.bat\n\n# On Mac/Linux\nchmod +x setup.sh\n./setup.sh\n```\n\n**Option 2: Manual Setup**\n```bash\n# 1. Install root dependencies\nnpm install\n\n# 2. Install server dependencies\ncd server\nnpm install\ncd ..\n\n# 3. Install client dependencies\ncd client\nnpm install\ncd ..\n```\n\n### Running the Application\n\n```bash\n# Start both frontend and backend\nnpm run dev\n\n# Or start separately:\nnpm run server  # Backend only (port 5000)\nnpm run client  # Frontend only (port 3000)\n```\n\n### Access URLs\n- **Frontend**: http://localhost:3000\n- **Backend API**: http://localhost:5000\n- **Health Check**: http://localhost:5000/api/health\n\n## 🧑‍💼 Demo Accounts\n\n### Speaker Account\n- **Email**: `demo.speaker@vibeathon.com`\n- **Password**: `demo123`\n- **Role**: Speaker\n\n### Event Manager Account\n- **Email**: `admin@vibeathon.com`\n- **Password**: `admin123`\n- **Role**: Event Manager\n\n## 🎯 Demo Flow\n\n### 1.
